# v3.19.1

58 changes since v3.19.0, most in the governance layer's command surface.

## What changes on upgrade

- `bernstein governance` now forwards to `bernstein govern` with a deprecation
  warning; it will be removed in a later release (#5010).
- An approval gate that timed out with no decision used to resolve as
  approved; every path now fails closed (#5051).
- Secret inspection runs on the post-tool hook path too (#4992).

## Governance surface

`bernstein govern` is the CLI for RBAC/budget verification, plan generation,
OTLP ingestion and discovery. OTLP spans from unscheduled runs become
receipted audit-chain entries, deduped, with coverage limits stated (#4962,
#4983, #5024). Policy decisions get one anchored record per evaluation
(#4912); `compliance coverage` reports per-control evidence (#4978); a paired
endpoint reports run coverage and verifies an uploaded receipt (#5067); audit
reports are chain-anchored, re-derivable (#5077); `governance plan` diffs the
declared posture against the environment (#4980); `verify pins` checks loaded
plugins and skills against a pinned manifest (#5089).

## Keys, secrets, trust records

An external secret store sits behind one contract — resolve, mint a
short-lived credential, report revocation — no value copies into Bernstein's
store (#4984). SSO tokens bind to the X.509-SVID that presents them (#5030);
receipt-signing keys rotate/revoke through a signed succession chain (#4211);
authority-envelope verification can pin an external key (#5064); audit
checkpoints anchor via RFC 3161 tokens (#5147). Also chain-recorded: session
revocation (#5031), model admission and drift (#5038, #5041), an MCP server's
tool-set changes (#4975). KMS adapters moved to a custody module (#5033).

## Receipts and verification

A signed refusal receipt failed offline verification: a caller passed a built
object where the verifier builds its own, and a broad exception guard hid it
(#2980). Also: `volunteer verify-bundle` re-runs a bundle's gates in a clean
worktree (#3871); diff-comment anchors bind to bytes, not lines (#3456);
signed TRACE 0.2 export (#4667); a reap receipt on every adapter kill (#5015);
W3C PROV-O export (#5039); invocation digests on scan results (#5151);
freshness checks for every entity kind (#5087); sensitivity propagated across
a lineage closure (#5042).

## Deterministic context and run records

An opt-in context pack folds co-change neighbours, the test-to-source map, the
nearest `AGENTS.md` and quarantined tests into one content-addressed prompt
section (#4522). `context manifest` (#3366) and `context segment-prompt`
(#3455) digest task inputs; repository-flow samples are byte-deterministic
(#4940) and feed a stagnation detector (#4941); `runs report` shows lifecycle
state and step timings (#5127); a lease primitive claims a TTL'd resource
(#5128).

## Adapters

New: Kimchi over ACP with session resume (#3100), Nmap (#3618), garak (#4839),
Skyvern (#4876). `adapters draft` proposes an invocation profile from an
installed CLI (#3763); gptme honours `max_tokens` (#4955); a feed-pinned Trivy
scan hashes the database it loaded (#4961); `bernstein activity` gained
research/data/ops subgroups (#4925).
